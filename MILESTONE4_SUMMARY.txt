WORKFLOWS
=========

Email Verification:
  1. User registers → verification token created + emailed
  2. User clicks email link → POST /auth/verify-email
  3. is_verified flag set to true
  4. Token revoked

Refresh Token:
  1. User logs in → access_token + refresh_token returned
  2. 30 min passes, access_token expires
  3. Client POST /auth/refresh with refresh_token
  4. New access_token issued (same refresh_token reused)
  5. Client continues authenticated

Logout:
  1. User clicks logout button
  2. POST /auth/logout (with valid access_token)
  3. All refresh_tokens revoked for user
  4. User must login again from all devices

Password Reset:
  1. User requests reset → token created + emailed (1-hour expiry)
  2. User clicks email link → visits frontend reset form
  3. Frontend POST /auth/reset-password with token + new password
  4. Password updated
  5. All refresh tokens revoked (force re-login everywhere)
  6. Reset token revoked
